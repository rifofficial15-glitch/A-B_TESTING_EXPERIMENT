# A-B_TESTING_EXPERIMENT
EXPERIMENT FOR A/B TESTING DESIGN USING PYTHON..


GOOGLE SEARCH NEW ALGORITHM A/B TESTING:

1. BUSINESS OBJECTIVE:
       DOES THE NEW SEARCH RANKING ALGORITHM IMPROVE USER SATISFACTION COMPARED WITH THE EXISTING RANKING ALGORITHM?
   PRIMARY OBJECTIVE:
       DETERMINE WHETHER USERS ARE MORE SATISFIED WITH THE SEARCH RESULTS WHEN USING THE NEW ALGORITHM...

2. HYPOTHESES:
   * NULL HYPOTHESIS: THE NEW SEARCH RANKING ALGORITHM DOES NOT IMPROVE THE USER SATISFACTION. Ho: new = old
   * ALTERNATIVE HYPOTHESIS: THE NEW SEARCH RANKING ALGORITHM IMPROVES THE USER SATISFACTION.  H1: new > old

3. CONTROL & TREATMENT GROUPS:
     CONTROL GROUP(A)  : 50% OF ELIGIBLE USERS CONTINUE RECEIVING SEARCH RESULTS FROM THE EXISTING RANKING ALGORITHM.

     TREATMENT GROUP(B): 50% OF ELIGIBLE USERS RECEIVE SEARCH RESULTS FROM THE NEW RANKING ALGORITHM.

4. SUCCESS METRICS:
     WE DIVIDE OUR METRICS INTO 3 CATEGORIES...

   A. PRIMARY METRICS:
           THESE METRICS DIRECTLY MEASURE USER SATISFACTION... THROUGH USER RATINGS AND SUCCESSFUL SEARCH RATES...
   B. SECONDARY METRICS:
           THESE HELP US UNDERSTAND USER BEHAVIOUR...
             1. CTR (CLICK THRU RATE)   : HOW FREQUENTLY USERS CLICK SEARCH RESULTS?
             2. LONG-CLICK RATE         : HOW MANY % OF SEARCHES RESULT IN A MEANINGFUL SUSTAINED CLICK?
             3. QUERY REFORMULATION RATE: HOW FREQUENTLY USERS CHANGE THEIR SEARCH QUERY BECAUSE THEY DIDN'T FIND WHAT THEY WANTED?
             4. SEARCH ABANDONMENT RATE : HOW MANY % OF SEARCHES WHERE USERS LEAVE WITHOUT A USEFUL INTERACTION?
   C. GUARDRAIL METRICS:
           GUARDRAIL METRICS ENSURE THAT THE NEW ALGORITHM DOESN'T NEGATIVELY AFFECT OTHER IMPORTANT ASPECTS OF THE GOOGLE SEARCH.
              1. SEARCH LATENCY    : DOES SEARCH BECOME SLOWER?
              2. ERROR RATE        : ARE THERE MORE TECHNICAL ERRORS?
              3. PAGE LOADING TIME : DOES THE SEARCH PAGE LOAD SLOWLY?
